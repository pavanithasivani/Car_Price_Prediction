🚗 Car Price Prediction Project

This project is a simple machine learning web application that predicts the resale price of a used car.
Users enter basic car details, and the system shows an estimated price.

📌 About the Project

When buying or selling a used car, it is often hard to decide the correct price.
This project helps users by predicting a fair resale value using past car data.

The application takes details like:

Car company

Car model

Year of manufacture

Fuel type

Kilometers driven

Based on these details, the system predicts the car’s resale price.

🧠 How It Works

Car data is collected and cleaned.

Important features are selected.

A Linear Regression model is trained to predict prices.

The trained model is connected to a web application.

Users enter details and get instant results.

🌐 Web Application

Backend is built using Flask

Frontend is created using HTML and CSS

The model gives real-time predictions through the website
